Connect any agent.

Paste one prompt into Claude Code, Codex or another coding agent. It installs Memvine and connects itself.

Read the prompt first 
Connect this machine to Memvine, the shared memory for my team's coding agents.

Project key: mv_sk_...
Email: the one `git config user.email` prints

If the key above still ends in "...", stop and tell me to put my project key there (it is under API keys at https://app.memvine.dev) and paste this again. Do not ask me for the key.

If you are Claude Code, run:
  claude plugin marketplace add memvine/memvine
  claude plugin install memvine@memvine
  node "$(ls -dt ~/.claude/plugins/cache/memvine/memvine/*/ | head -1)bin/memvine-hook.mjs" connect <key> <email>

If you are Codex, run:
  codex plugin marketplace add memvine/memvine
  codex plugin add memvine@memvine
  node "$(ls -dt ~/.codex/plugins/cache/memvine/memvine/*/ | head -1)codex/bin/memvine-codex.mjs" install <key> <email>
Then remind me to type /hooks in Codex and trust the five memvine hooks.

If you are another agent, stop and point me to https://github.com/memvine/memvine#quick-start.

Run nothing else. Tell me what each command printed, never the key, and tell me to start a new session when it is done.

Run it yourself.

Memvine is open source under the MIT license. One Docker command starts the server and the console on a machine you control. The hosted service at app.memvine.dev is open by invitation.
